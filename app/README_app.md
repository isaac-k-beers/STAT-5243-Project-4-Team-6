# Cooperstown Calculator Shiny App

This enhanced R Shiny app is the interactive dashboard for the Project 4 MLB Hall of Fame prediction pipeline.

## How to run

From the project root:

```bash
R -e 'shiny::runApp("app")'
```

Or from inside the `app/` folder:

```bash
cd app
R -e 'shiny::runApp(".")'
```

The app requires `app/model_predictions.csv`, which is generated by:

```bash
python scripts/03_train_models.py
```

## What the app includes

- Overview tab with model leaderboard and source coverage.
- Player Explorer with searchable player selection, predicted Hall of Fame probability, career profile percentiles, and similar historical players.
- Rankings tab with filters by role, archetype, actual induction status, and probability range.
- Archetypes tab with cluster profiles, top players in each archetype, prediction distribution, and PCA figure.
- What-if Similarity tab that compares a custom candidate profile to nearest historical players.
- Model & Methods tab with evaluation table, feature importance, PR curve, and calibration curve.

The app does not retrain the Python model live. It reads the final model outputs generated by the Python pipeline and turns them into a user-friendly dashboard.
